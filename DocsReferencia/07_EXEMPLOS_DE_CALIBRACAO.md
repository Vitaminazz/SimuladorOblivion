# Exemplos preliminares para calibrar ranks

**São exemplos de cálculo, não requisitos de habilidades nem calibração aprovada.** Os pesos são a base de trabalho aceita; as notas e fronteiras dos ranks continuam sujeitas a revisão.

## Regra usada nestes exemplos
- Medidores de 0 a 5; score base `Σ peso × nota/5`.
- Pesos: potência/impacto 30, área/alvos 15, alcance 10, duração 10, controle 10, versatilidade 10, interação com defesas 15.
- Faixas preliminares: B = 30–39; A = 40–49; S = 50–64; SS = 65–79. (Consultar proposta completa para F/D/C/SSS/U.)
- Dano Real desligado: interação com defesas é avaliada pelas demais propriedades defensivas do poder; Dano Real ligado: essa dimensão recebe 5/5. O modificador é binário, sem bônus ou escala parcial.

## Exemplo 1 — golpe físico que projeta rajadas (FOR)
Notas ilustrativas: potência 3, área 1, alcance 1, duração 0, controle 3, versatilidade 1, interação 0.

`30×3/5 + 15×1/5 + 10×1/5 + 10×0/5 + 10×3/5 + 10×1/5 + 15×0/5 = 31`

**Rank preliminar: B.** A descrição pode dizer que o golpe produz uma rajada física moderada; o status FOR explica a fonte, enquanto a nota de potência representa o resultado pretendido.

Se esse mesmo poder tiver **Dano Real ligado**, a dimensão de defesa passa de 0/5 a 5/5: `31 + 15 = 46`, que cruza para **A**. Isso eleva o rank de forma visível, sem somar um bônus artificial adicional. O golpe ainda pode ser bloqueado/desviado; se atingir Indestrutível, provoca reação/efeito, mas não o destrói.

## Exemplo 2 — projétil mágico de longo alcance (INT)
Notas ilustrativas: potência 2, área 1, alcance 5, duração 0, controle 4, versatilidade 2, interação 0.

`12 + 3 + 10 + 0 + 8 + 4 + 0 = 37`

**Rank preliminar: B.** INT inspira uma manifestação mágica; alcance máximo e controle elevado são parte do perfil. Números e DPS na Sandbox seriam sinalização visual representativa, não promessa de equilíbrio matemático.

## Exemplo 3 — aura de suporte persistente (HAR)
Notas ilustrativas: potência/eficácia 2, área 3, alcance 1, duração 5, controle 4, versatilidade 3, interação 0.

`12 + 9 + 2 + 10 + 8 + 6 + 0 = 47`

**Rank preliminar: A.** Aqui potência/impacto significa a eficácia principal da aura, não dano. A duração, área e controle contribuem ao rank.

## O que os exemplos sugerem
- O componente verdadeiro de Dano Real pode acrescentar até 15 pontos na ponderação atual. No exemplo FOR, ele eleva B para A.
- O aumento final depende do score inicial e das fronteiras de ranks; a mesma diferença de pontos pode cruzar uma fronteira ou permanecer no mesmo rank.
- Selo visual “Dano Real” comunica a propriedade mesmo se o poder já estiver numa faixa alta e o rank não mudar.
- A nota 5/5 do medidor não significa “uma versão muito forte” da propriedade: o próprio Dano Real permanece ligado/desligado. As demais notas desse medidor descrevem outras formas de interação com defesas, se forem aprovadas.
- Atributo/status serve de origem e contexto para os feitos; evitar convertê-lo em pontos adicionais e contar a potência de novo.

## Questões para revisão
1. Parece apropriado que Dano Real possa acrescentar até 15 pontos e, neste exemplo, elevar o poder de B para A?
2. O nome “potência/impacto” é claro para abranger dano, cura, suporte e outros efeitos, ou prefere “eficácia do efeito principal”?
3. Os três perfis (rajada física, projétil mágico, aura de suporte) são exemplos úteis para seguir calibrando a escala?
